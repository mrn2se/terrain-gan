Privacy

What this site does

The site is static. It sets no cookies, has no analytics, advertising, accounts or forms, and stores nothing in your browser beyond its usual cache. The terrain is computed in your browser tab, and nothing you do on the map is sent anywhere. This project collects no personal data and receives no visitor logs.

Hosting by GitHub

The site is hosted on GitHub Pages, which logs and stores visitors' IP addresses for security purposes. GitHub is responsible for this, and for any cookies or other data processing connected with the hosting. For how GitHub handles your data, and for your rights and requests about it, see the GitHub General Privacy Statement.

Libraries loaded from jsDelivr

The three libraries above are loaded from the public jsDelivr CDN (cdn.jsdelivr.net), so your browser also contacts jsDelivr, which receives your IP address and the usual request data. See the jsDelivr privacy policy. This page itself loads nothing from there.
